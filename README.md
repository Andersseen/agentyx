# Agnox

Agnox is provider-agnostic tooling for coding-agent environments.

Status: early development. The repository currently contains only the initial monorepo foundation.

## Requirements

- Node.js >=22
- pnpm 10.30.1

## Setup

```sh
pnpm install
```

## Development

```sh
pnpm agnox --help
pnpm agnox --version
pnpm build
pnpm test
pnpm typecheck
pnpm lint
pnpm format
pnpm check
pnpm clean
```
