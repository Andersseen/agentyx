The review informed the split between visual direction, task usability, interaction states,
design-system reuse, product copy and bounded rendered verification. It also reinforced progressive
disclosure: focused Skills are more useful than a single design handbook or a bundled data set.

No upstream Skill, asset, checklist, database or distinctive wording was vendored or copied. The
Anthropic source has reproduction/derivative-work considerations, so Agentyx's built-in Skills were
written independently from generally established UI/UX practice. No researched source was added to
Agentyx's trusted-source registry.
