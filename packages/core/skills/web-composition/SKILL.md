# Web composition

Use this when laying out a landing page, product site or editorial page. Do not design a section as a
container; decide what experience that part of the story should produce, then choose the structure
that delivers it.

## Start from the story, not the template

List the beats the visitor should move through, and for each one name the intended effect: orient,
prove, explain a mechanism, relieve, convince, invite action. Only then choose layout. If two beats
would end up as the same grid of cards, one of them is probably mis-designed.

## Composition levers

Choose the few that serve the concept:

- asymmetric grids and editorial splits where text and visual carry unequal weight;
- one full-bleed or edge-to-edge moment instead of many boxed ones;
- a persistent rail or axis that other content hangs from;
- deliberate overlap or offset that links two ideas, used sparingly;
- diagrams and data used as the layout itself, not placed beside it;
- large type as a structural shape;
- dense areas followed by generous negative space, so rhythm is felt;
- sections that hand off to the next through a shared line, color shift or aligned element.

Vary width, alignment and density between sections. Uniform max-width, uniform padding and uniform
centering read as a template.

## Responsive recomposition

Decide for each composition how it behaves at narrow widths. Prefer reordering, cropping, changing
the diagram's orientation or replacing a wide visual with a compact equivalent over stacking
everything. Code, tables and diagrams must stay usable: scroll them deliberately inside their own
region rather than letting the page overflow.

## Boundaries

Reading surfaces such as documentation articles and legal pages keep a calm, predictable column.
Use native layout around existing design-system primitives instead of wrapping every region in the
same card component.

## Stop condition

Stop when each beat has a distinct purpose and shape, the first viewport communicates the product,
and no layout choice exists only to look different.
