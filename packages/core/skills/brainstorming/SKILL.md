# Brainstorming

Use this before substantial ambiguous design work, not for obvious small edits.

Clarify the objective, constraints, users, architecture implications, alternatives, and acceptance
criteria. Ask only the questions that change the implementation. Once the shape is clear, summarize
the chosen direction and the tradeoffs that matter.
