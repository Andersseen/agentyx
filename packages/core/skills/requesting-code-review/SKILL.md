# Requesting code review

Ask for review when a change affects behavior, public APIs, security, data integrity, or several
modules.

Provide the requirement, changed files, verification performed, and known risks. Ask the reviewer to
focus on requirement compliance, correctness, regressions, tests, security, and unnecessary
complexity. Treat findings as inputs to resolve, not as a substitute for your own judgment.
